## 1. The equations first

### 1.1 The functional class (all on-disk instruments)

For a configuration c (any texture M(x), any dressing b(r), any family, any box) rotating
under a fixed generator map with velocity field a0(c) and frequency ω:

```text
E(c, omega) = E_stat(c) + omega^2 * kin(c),      kin(c) = 4 sum_i <comm_eta(a0, A_i)>^2_eta
```

This is EXACT, not a truncation: F_0i is linear in ω (chain rule on the orbit), so the
kinetic energy carries no ω-terms beyond quadratic, and kin is t-invariant along the orbit
(measured: § 3, rel. deviation 1.3e-11).

### 1.2 The envelope-concavity theorem (the structural answer)

Write u = ω². For ANY configuration set C:

```text
E*(u) = inf_{c in C} [ E_stat(c) + u * kin(c) ]
```

is an infimum of affine functions of u, hence CONCAVE in u. Consequences:

| Claim | Argument |
| --- | --- |
| No strict interior minimum in u | a concave function has no strict interior minimum |
| No strict interior minimum in ω | dE\*/dω = 2ω·E\*'(u); at a stationary ω0 > 0, d²E\*/dω² = 4u·E\*''(u) ≤ 0: a maximum or flat, never a strict minimum |
| Independent of everything in C | the argument never uses what C is: texture, guarded or unguarded dressing, box radius, both s signs, any family |
| The dichotomy | at the free minimizer, either kin_tot > 0 (E\* increasing: the minimum sits at ω = 0, the M5.21.3 verdict) or kin_tot < 0 (E\* decreasing: RUNAWAY, no minimum) |

So free energy minimization can never produce the asked-for minimum on this functional
class. The author's own qualifier names the escape: "for electron analog WITH ANGULAR
MOMENTUM". Fixing J breaks the envelope argument (the constraint set depends on ω), and the
minimum exists there (§ 5).

### 1.3 The fixed-J bridge

J = dE/dω = 2ω·kin. At fixed J the feasible configurations at frequency ω satisfy
kin(c) = J/(2ω), and:

```text
E(omega)|_J = min_{c: kin(c) = J/(2omega)} [ E_stat(c) + omega * J / 2 ]
E(J)        = min_omega E(omega)|_J = min_c [ E_stat(c) + J^2 / (4 kin(c)) ],   omega* = J / (2 kin)
```

ω → 0 forces kin → ∞ (expensive static energy), ω → ∞ forces kin → 0 (out of the family's
reach): the tradeoff produces an INTERIOR minimum at ω\* > 0. This is the M5.21.9
constraint-carried electron, now with the M5.21.14 guarded dressing coupled in.

**Branch restriction (audit round 1 correction, adopted)**: the J²/(4·kin) term is a barrier
only on the kin > 0 branch (+∞ as kin → 0⁺); on the kin < 0 branch the same term is an
unbounded REWARD (−∞ as kin → 0⁻), and the guarded family DOES reach kin < 0 inside the
trust region (measured: the plateau slice crosses zero below \|a\| = 0.25). So the fixed-J
minimum is well defined only branch-restricted to kin > 0 (physically: a rotating state
needs positive effective inertia; the negative-kin branch IS the free runaway channel), and
the explicit KIN_FLOOR barrier in the scripts is load-bearing, not redundant.

### 1.4 Scope (what the theorem does NOT cover)

| Not covered | Why |
| --- | --- |
| Higher-than-ω² kinetic terms | the premise is the exact quadratic; a velocity-coupled regularization potential ([Q25](../m5_question_tracker.md#q25-detail)) or retardation would void it |
| The spatial twist channel | E(k) has a LINEAR term in the twist wavenumber k (M5.21.3 P2): spontaneous SPATIAL twist selection is not excluded, only time-frequency selection |
| Constrained minimization | fixed J is exactly the covered escape (§ 1.3) |
